# DJI Osmo Action 4 · 交互式 3D 拆解实验室

一个完全由代码生成的 DJI Osmo Action 4 三维拆解可视化页面。没有外部 3D 模型文件、图片素材或在线字体，机身、镜头、屏幕、主板、电池、散热、接口等 11 个模块全部使用 Three.js 几何体与 Canvas 程序化纹理实时构建。拆解时各部件按自身中心缩放、整机轻微后仰，拉开前后层距，避免模块互相穿插。

## 运行

页面使用 ES Module + import map，需要通过 HTTP 打开，不能直接双击 `index.html`。

```bash
# 在本目录打开终端
python -m http.server 8899 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8899/>。

Windows 下也可以直接双击 `start.bat`，脚本会自动启动本地服务器并打开浏览器。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 环绕旋转视角 |
| 滚轮 / 双指捏合 | 缩放 |
| 单击机身部件 | 选中模块，触发分步拆解动画，右侧显示解析 |
| 双击部件 | 选中并将镜头推进到该部件 |
| 单击空白处 | 取消选中并回到总览 |
| 拆解滑杆 | 0–100% 手动控制拆解进度 |
| 右侧「开始拆解」 | 一键展开全部 11 个模块，再次点击重新组装 |
| 全部拆解 / 组装复位 | 一键展开或合拢 |
| 自动旋转 | 开关缓慢的展示旋转 |
| 标注 | 显示 / 隐藏部件引线与名称 |
| 视角 | 回到默认机位 |
| `E` / `R` / `L` / `V` / `H` / `Esc` | 拆解 / 组装 / 标注 / 视角 / 帮助 / 关闭 |

选中部件后，右侧「部件解析」展示其作用、关键参数、结构标签和当前世界坐标；「聚焦此部件」会将镜头平滑推进，「返回全景」回到总览。

### 性能与防眩晕

- 默认关闭自动旋转，避免镜头持续转动造成眩晕；需要展示时可手动打开「自动旋转」。
- 拖拽 / 缩放期间会自动暂停 Bloom 辉光，停下约 200ms 后恢复，优先保证操作跟手。
- 右上角太阳图标为**性能模式**：关闭辉光、降低渲染倍率，适合低配显卡或高分屏。
- 页面加载后会采样约 3 秒帧率；低于阈值时自动进入性能模式并提示一次，可随时点太阳图标恢复。
- **选中部件不再使用发光描边**，避免闪烁晃眼；选中状态由左侧清单高亮、右侧解析面板和静态角框定位共同反馈。
- 标注文字以约 25fps 更新，且不再每帧读取 DOM 尺寸，明显减少旋转时的卡顿。
- 支持系统 `prefers-reduced-motion`：开启后禁用阻尼与自动旋转，拆解动画直接切换。

## 功能结构

- **程序化模型**：圆角挤出壳体、镜筒与多层镜片、屏幕、PCB、导热鳍片、电池、按键、磁吸底座、接口等；全部位于 `model.js`。
- **拆解动画**：每个模块拥有独立的爆炸位移与错峰进度，`modelRoot` 在拆解时轻微收缩，避免部件冲出画面。
- **视觉系统**：ACES 色调映射、Bloom、PMREM 反射环境、程序化地面网格、粒子与接触阴影；主视觉放大机身，右侧大标题 + 橙色主按钮建立单一眼焦点；选中反馈使用静态角框，减少闪烁和每帧额外 Pass。
- **标注引擎**：将 3D 锚点投影到屏幕，自动分列、避让并在标签与部件间绘制折线引线；移动端只显示选中部件的标注。
- **信息架构**：11 个模块的参数数据位于 `data.js`，与模型和 UI 解耦。
